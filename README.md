# 🎮 PUBG Clone Website

A modern and responsive PUBG-inspired website built using **HTML, CSS** with immersive gaming UI, animations, and interactive sections.

---

# 📌 Overview

This project is a PUBG Clone Website designed to deliver a modern gaming experience through stylish visuals, smooth animations, and responsive layouts inspired by PUBG Battlegrounds.

The project is built completely using:
- HTML5
- CSS3
- JS(ES6+)

---

- Modern Gaming Interface

```bash

```

## Navigate to Project Folder

```bash
cd pubg-clone
```

## Open Project

Simply open `index.html` in your browser.
